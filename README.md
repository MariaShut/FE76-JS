1) Скачать и установить гит.
2) Скинуть мне в телеграм никнейм гитлаб (см. скриншот "никнейм_гитлаб.png").
3) Я добавлю вас в наш учебный репозиторий.
   Нужно принять и подтвердить доступ в письме, которое придет на почту. 
4) Перейти в папку с проектом в гитлаб. 
5) Склонировать репозиторий с помощью комманды git clone <link-to-repo>.
6) Перейти в терминале в папку репозитория - команда cd <folder-name>
7) Создать новую ветку из main со своим именем и фамилией. 
   Использовать комманду git branch name.
   Пример названия ветки: ivan-ivanov-main (команда - git branch ivan-ivanov-main)
8) Перейти в свою основную ветку (только что созданную) с помощью комманды git checkout ivan-ivanov-main.
9) Отправить данную ветку в удаленный репозиторий с помощью комманды (git push --set-upstream origin ivan-ivanov-main).

10) Из своей основной ветки создать еще одну git branch feature/ivan-ivanov-hw_15.
   Пример названия второй ветки: feature/ivan-ivanov-hw_15
11) Перейти в новую ветку.
12) Отправить данную ветку в удаленный репозиторий с помощью комманды (git push --set-upstream origin feature/ivan-ivanov-hw_15).
13) Создать файл index.html с базовой разметкой.
14) Затем использовать комманду git add .  (пробел и точка!)
15) Закоммитить все файлы, используя комманду git commit -m 'init: start work with Git'.
16) Отправить свой коммит в удалённый репозиторий - git push
17) Перейти на сайт gitlab, на вкладку Merge requests и нажать 
    на кнопку Create merge request (см. скриншот "кнопка_создать_мердж_реквест.png").
18) Заменить ветку, в которую хотите отправить свои изменения:
    Под заголовком New merge request нажать на кнопку Change branches (см. скриншот "change_branches.png")
    Указать нужные ветки:
    Source branch - ветка-источник, ветка с вашей домашкой: feature/ivan-ivanov-hw_15
    Target branch - целевая ветка, куда отправить ваши изменения: ivan-ivanov-main

    После этого нажать на кнопку Compare branches and continue
19) Дальше сделать всё как на скриншоте "создать_мердж_реквест.png".
20) Ваш мердж реквест должен появиться на вкладке Merge requests
Done!
